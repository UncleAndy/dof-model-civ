# Отменённые прогоны (до реализации настоящего прогноза)

Эти записи собраны на версии движка, в котором поиск решения **не прогнозирует
будущие ситуации**: на каждом уровне поиска переиспользуется тот же список
кандидатов с постоянными дельтами, дисконта нет, набор возможностей для будущего
состояния не перевыводится. Такой поиск перебирает «нынешнее меню, повторённое N
раз», а не «то, что откроется после действия».

Решение (2026-09-27, пользователь): **такие прогоны не имеют смысла как проверка
DOF-Core и остановлены.** Здесь они оставлены только как история:

* `duel_*_a.json`, `duel_*_b.json` — записи сторон,
* `duel_*_a.log`, `duel_*_b.log` — логи сторон (включая диагностику `[замер]`,
  `[вето ядра]`, `[выбор-пуст]`, `[thaw …]`).

**Чего в них НЕЛЬЗЯ читать:**

* что «любопытство работает» или «не работает» — прежние числа (+2.62; +4.25)
  описывают поведение прежней реализации, а не свойства DOF-Core: раз движок не
  прогнозирует, эти сравнения мерят взаимодействие дефицита с надбавкой;
* что модель площадки, цены хода или замерзания «доказаны» — все выводы о
  замерзании сохраняются только как описание симптома прежнего движка.

**Что сохраняет силу** (не зависит от прогноза): измеренная легенда карты
(террейны, экстры, центр города = минимум 1), правило «измеренный ноль — знание»,
реестр клинчей, набор инструментов дуэли (перестановка сторон, фильтры, отчёты),
и факт замерзания как **предельного исхода правила «строго > 0»** — он понадобится
как тест: после настоящего прогноза замерзаний быть не должно.
