# DOF-политика во встроенном ИИ freeciv — рабочий набор

Состояние: **M0, M1, M2, M3 исполнены и проверены прогонами** (2026-10-25). Ниже — что именно лежит в контейнере `freeciv-web` и как это измерять.

Полное описание изменений в движке (по файлам, с кодом, замерами и границами изменения): `drafts/DOF_ENGINE_CHANGES.md`. Здесь только рабочий набор.

`orig/` (девственные копии правленых файлов) в репозиторий не кладётся: его всегда можно достать из контейнера —
`docker cp freeciv-web:/docker/freeciv/freeciv/<путь> deploy/freeciv-dof/orig/<имя>`; диффы в `patches/` сняты именно с них.

## Что изменено в движке

Новые файлы (кладутся в `/docker/freeciv/freeciv/ai/default/`):

| файл | назначение |
|---|---|
| `dofpolicy.h` | API политики: `dof_enabled`, `dof_is_source`, журнал |
| `dofpolicy.c` | чтение политики, журнал событий (ledger), журнал решений |

Патчи существующих файлов (см. `patches/`):

| патч | что делает |
|---|---|
| `meson.build.patch` | `dofpolicy.c` в `libfc_ai.a`, `ai/default` в `server_inc` |
| `aiiface.c.patch` | `dof_ledger_note()` в `call_incident()` — глобальный журнал событий |
| `classicai.c.patch` | регистрация `player_console` (`/aicmd <player> dof on|off|status`) |
| `daidiplomacy.c.patch` | M1-гейты (желание войны, «война за добычей», «no mercy», союзники, космос, предохранитель в `dai_go_to_war`), M3 (война против источника по факту нападения; перемирие без выкупа), счётчик подавленного желания, журнал объявлений |
| `daiactions.c.patch` | M2: подкуп, саботаж, кража технологии/золота, яд, чума, ядерный удар шпионом против не-источника вне войны → utility 0 (посольства разрешены) |
| `daiunit.h.patch` | `POTENTIALLY_HOSTILE_PLAYER` — незнакомец не цель для DOF-места |
| `srv_main.c.patch` | безлюдная игра (нет людей вообще) сама листает ходы — иначе прогон встаёт на T001 без клиента |
| `daisettler.c.patch` | **не DOF**: отладочный `log_normal` веб-форка разыменовывал NULL `cityresult` → segfault после ~50 ходов. Без этой правки любой длинный прогон падал |

## Переключатель

Файл в контейнере `/docker/freeciv/dof_policy.conf` (или `DOF_POLICY_FILE`), одна строка:

```
none | all | even | odd | 0,2,4      # комментарий
```

`even`/`odd` выбирают места по индексу игрока — так **обе руки играют одну партию**: половина мест классическая, половина DOF. По умолчанию в контейнере стоит `none`, то есть живой стенд ведёт себя как раньше.

Плюс консоль `aicmd <player> dof on|off|status` — для точечной проверки на живом клиенте.

## Журнал (что писать в разбор)

Все строки — префикс `[DOF]` в серверном логе:

```
[DOF] policy=<spec> turn=N
[DOF] roster ai_seats=[Имя:idx=0:dof=1,...]
[DOF] contact turn=N me=X other=Y status=MET|SOURCE
[DOF] declare turn=N declarer=X target=Y declarer_dof=0|1 reason=N
[DOF] attack turn=N violator=X victim=Y violator_dof=0|1 victim_dof=0|1
[DOF] news turn=N violator=X victim=Y violator_dof=0|1
[DOF] rule turn=N me=X other=Y what=war_on_source|ceasefire_offer|coercion_refused
[DOF] desire_suppressed turn=N me=X other=Y n=1     (первое подавление пары)
[DOF] blocked turn=N me=X other=Y what=declare_war
```

`declare`/`attack`/`news` пишутся **всегда**, обе руки — иначе «тихая» партия неотличима от «прибор не сработал».

## Что изменено на самом стенде (2026-10-25)

Файлы стенда вне движка, копии — в `stand/`:

* `/docker/scripts/install/dependency-services-default-start.sh` (её и есть симлинк `dependency-services-start.sh`) — MariaDB поднимается напрямую через `mariadbd-safe`: исходная строка `pidof mysqld || service mariadb start` в этом образе не работает (нет `service`, процесс называется `mariadbd`), плюс принудительный `chmod 1777 /tmp`. Без этого не стартовала база → прокси на 7002 падал в `check_user` (`cursor.close()` на None) и партии через клиент не шли вообще.
* `/docker/publite2/init-freeciv-web.sh` — `addArgs --debug 1` → `--debug 2` (иначе `log_normal` подавлен и строк `[DOF]` не видно).
* `/docker/freeciv/dof_policy.conf` — по умолчанию `even`: половина ИИ-мест ведёт себя по DOF. Переключение — одна строка, без рестарта.

**Журнал на стенде читать из stderr**, а не из `freeciv-web-log-<port>.log`: в этом окружении файл `--log` не обновляется (свежие — от 21.10), поэтому `dof_log` дублирует строки в stderr → `/docker/logs/freeciv-web-stderr-<port>.log`. Проверено живой партией через клиент:

```
[DOF] policy=even turn=1
[DOF] roster ai_seats=[Muhammad ibn Abdalla:idx=1:dof=0,Nicolás de Federmán:idx=2:dof=1,Amílcar Cabral:idx=3:dof=0]
```

## Как включить DOF на стенде (проверено)

Обновление кода в движке = `sh deploy/freeciv-dof/apply.sh` + `docker restart freeciv-web` (без рестарта живущие движки держат старый inode).
А включение политики рестарта **не требует**: файл читается в начале хода каждого ИИ-места, смена видна со следующего хода (проверено: файл переписан на ходу 5 — в журнале `policy=even turn=69` и новый состав мест; задержка — время генерации карты, а не кэш).

1. Выбрать руку — записать в `/docker/freeciv/dof_policy.conf`:
   * `all` — все ИИ-места ведут себя по DOF (войн не начинают вовсе);
   * `even`/`odd` — половина мест по DOF, половина классических (так идёт замер);
   * `0,2,4` — явный список индексов мест.
2. Поднять журнал: в `/docker/publite2/init-freeciv-web.sh` строка `addArgs --debug 1` → `--debug 2`, иначе строки `[DOF]` в `/docker/logs/freeciv-web-log-<port>.log` не пишутся (изменение требует рестарта контейнера).
3. Наблюдать: `docker exec freeciv-web grep "\[DOF\]" /docker/logs/freeciv-web-log-6001.log`.
4. Вернуть стенд в исходное: `none` в файле политики — со следующего хода все места снова классические.

Новая партия в том же процессе движка (`--keep`) чистит журнал источников и счётчики: ход пошёл назад — состояние обнуляется.

## Уровень логирования (важно)

Журнал идёт через `log_normal`, поэтому на **живом стенде** строки `[DOF]` не видны: publite2 запускает движки с `--debug 1`. Для наблюдения на стенде нужен `--debug 2` (или выше) в аргументах движка; безлюдные прогоны `run_ab.py` пишут лог по умолчанию, там журнал есть.

## Запуск серии

```bash
.venv/bin/python deploy/freeciv-dof/run_ab.py --games 4 --turns 120 \
    --aifill 8 --size 3 --par 4
```

Скрипт готовит `.serv` и файл политики внутри контейнера, поднимает безлюдные сервера на портах 61xx, ждёт выхода, забирает лог, вытаскивает журнал, пишет `logs/ab/series.jsonl` и печатает сводку.

## Замер 2 (12 партий × 2 руки, 121 ход, 8 мест, карта size 2, M1+M2+M3)

| рука | мест | объявлений | без повода | на место |
|---|---|---|---|---|
| контроль (`none`) | 96 классических | 112 | 108 (96%) | 1.17 |
| DOF (`even`) — DOF-места | 48 | 3 | **0 (0%)** | **0.06** |
| DOF (`even`) — классические места тех же партий | 48 | 53 | 49 (92%) | 1.10 |

Все три объявления DOF-мест — против того, кто **лично** на них напал (проверено строже: не «нападал на кого-то», а «нападал на этого объявителя»). Правило срабатывало: `coercion_refused` 64 раза, `ceasefire_offer` 304, `war_on_source` 2, подавленных пар желания 267. Ни одна партия не упала.

## Первый замер (4 партии × 2 руки, 121 ход, 8 мест, карта size 3, только M0+M1)

| рука | мест | объявлений | из них без повода | атак |
|---|---|---|---|---|
| контроль (`none`), 4 игры | 32 классических | 36 | **33 (92%)** | 5 |
| DOF (`even`), DOF-места | 16 | 3 | **0** | 1 |
| DOF (`even`), классические места в тех же играх | 16 | 9 | 8 (89%) | 3 |

«Без повода» = цель объявления до этого хода ни на кого не нападала (по журналу `attack`).

Чтение: классическое место объявляет войну ради выгоды/неприязни в 92% случаев; DOF-место — только против того, кто уже напал (3 случая из 3: Сукарно против Теводроса, Рама Тибоди дважды против Суйко). Классические места в тех же партиях ведут себя как в контроле — смешение рук внутри партии на них не влияет.

## Чего ещё нет

* Упаковка в собственный `aitype dof` (сейчас — флаг на место в классическом типе).
* Проверка против **нашего** агента (Python-клиент) и в мультиплеере с людьми: серии пока безлюдные, все места — встроенный ИИ.
* Долгие партии (>120 ходов) и карты size 4–5: там войны классического ИИ идут позже, серия не покрыта.
* `blocked` (предохранитель в `dai_go_to_war`) в сериях = 0: до него не доходит, всё гасится на желании войны. Это ожидаемо, но метрика «сколько раз укусило» теперь считается через `desire_suppressed`.
