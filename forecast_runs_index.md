# Индекс прогонов дня: включение прогноза (2026-09-27)

Зачем этот файл. За день прошло около двадцати коротких прогонов, часть из них
сломана моими же ошибками. Без индекса они выглядят одинаково — «какой-то smoke».
Здесь у каждого артефакта: что проверялось, чем кончилось и, если прогон
отброшен, — **почему** (правило A/B требует сообщать отброшенное с причиной).

Файлы лежат рядом, в корне проекта. Записи о клинах — в `wedged_actions.json`,
измеренные факты о типах — в `measured_facts.json`.
