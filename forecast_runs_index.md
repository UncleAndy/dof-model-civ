# Индекс прогонов дня: включение прогноза (2026-09-27)

Зачем этот файл. За день прошло около двадцати коротких прогонов, часть из них
сломана моими же ошибками. Без индекса они выглядят одинаково — «какой-то smoke».
Здесь у каждого артефакта: что проверялось, чем кончилось и, если прогон
отброшен, — **почему** (правило A/B требует сообщать отброшенное с причиной).

Файлы лежат рядом, в корне проекта. Записи о клинах — в `wedged_actions.json`,
измеренные факты о типах — в `measured_facts.json`.

## Что из этого следует для A/B

Ветви готовы: обе проходят 30 ходов без ошибок, различие по действию видно уже на
одной игре (31 действие при 0 простоях против 9 при 23). Правило вердикта и фильтры
зафиксированы в `drafts/DOF_CALIBRATION.md` §10.19 **до** данных; серия не запущена.

Инструмент вердикта — `scripts/ab_two_arm_verdict.py` (правило §10.19 целиком:
фильтры, непарный bootstrap-интервал, отказ от вердикта на недоборе). Проверка на
двух записях выше:

```
python scripts/ab_two_arm_verdict.py --on forecast_smoke16.json --off forecast_off_smoke3.json
→ ВЕРДИКТ: недобор: 1/16 и 1/16 чистых — вердикта нет
```
